# Казанок 🍲

Книга рецептів, список покупок, меню на тиждень і режим готування з таймерами.
Це веб-додаток (PWA): працює на iPhone як звичайний додаток, офлайн, без сервера.

## Можливості
- Рецепти з фото, категоріями, пошуком та улюбленими
- Розпізнавання рецепта з тексту (опис з TikTok, Instagram, сайту): назва, інгредієнти, кроки
- Перерахунок інгредієнтів під кількість порцій
- Калорії та БЖВ на порцію (вбудований довідник продуктів) і денна норма за вагою, зростом і віком
- Список покупок: додавання з рецепта одним натиском, сумування однакових продуктів, групи за відділами магазину, «Поділитися»
- Меню на тиждень: вручну або автоматично, усе меню можна одним натиском додати в покупки
- Режим готування: великий текст, екран не гасне, таймери автоматично знаходяться в тексті кроку («10 хв»)
- Можна поділитися рецептом через посилання: рецепт закодований прямо в ньому
- Експорт та імпорт резервної копії (JSON)

Усі дані зберігаються локально на пристрої (localStorage).

## Публікація на GitHub Pages
1. Створіть репозиторій на github.com (наприклад, `kazanok`), Public.
2. Завантажте в нього всі файли з цієї папки: **Add file → Upload files**.
3. Відкрийте **Settings → Pages → Build and deployment**, у полі Source виберіть «Deploy from a branch», гілку `main` і папку `/ (root)`, потім натисніть Save.
4. Приблизно за хвилину додаток зʼявиться за адресою `https://<ваш-логін>.github.io/kazanok/`.

## Встановлення на iPhone
Відкрийте адресу в **Safari**, натисніть «Поділитися» і виберіть «На екран „Додому“».

## Оновлення
Після змін у файлах збільште номер версії `CACHE` у `sw.js` (наприклад, `kazanok-v2`), інакше телефон показуватиме стару версію з кешу.
